# 激浪前端液态玻璃视觉更新

## 本版内容
- 新增 `css/liquid-glass.css`，在公共布局、卡片、按钮、导航、输入框和主要页面标题区统一使用品牌蓝液态玻璃视觉。
- 在全站背景中加入冰蓝环境光与液态波浪，透明区域可透出波浪层。
- 修复数据资产 Hero、普通业务页面标题区和登录页的波浪资源引用：统一指向 `/media/liquid-wave.svg?v=3`。
- AI 助手空态取消不透明灰底，沿用全局背景氛围。
- 继续保持品牌蓝 `#1B6EF3`，数据表格采用更实的表面以保证可读性。
- 更新 `design.md`，补充全站背景与可访问性回退规范。

## 更新方式
将本压缩包中的 `frontend` 目录与当前项目对应目录合并或替换，并确认服务端将 `frontend/assets/` 挂载到 `/media/`、`frontend/css/` 挂载到 `/css/`。如使用浏览器缓存，可执行 Ctrl+F5 强制刷新。

## 验证说明
已检查所有 JavaScript 文件语法、CSS 大括号结构以及新增样式表的 CSS 解析。该工作环境无法访问用户本机的 `127.0.0.1:8000` 站点，因此未对用户实际部署环境完成浏览器截图验收；替换后请在本地确认背景资源 `/media/liquid-wave.svg?v=3` 返回成功。
