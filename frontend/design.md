# 激浪 · 反调印刷（DISSONANCE PRESS）设计规范 v3.0

> 2026-11-07 定稿。本版取代 v2.0（shadcn/ui · Nova）。
> 唯一真源：`frontend/src/styles/tokens.css`。改数值改这里，页面不得自造。
> 品牌资产：Logo 为「错版浪」单色墨版（`/media/logo-mark.svg`，套件见 `docs/brand/logo-v3/`），
> favicon 为酸柠底墨浪；名称「激浪」与界面主操作色品牌蓝 `#1B6EF3` 不动。

---

## 1. 这套语言是什么

把工作台当成一张**错版印刷的工业海报**来做：新粗野骨架 + 丝网印套准偏差 + 中文竖排 + 三语体对撞。

不和谐是算出来的，不是随手撞。它有自己的纪律，纪律见 §3 与 §4。

设计关键词：**硬、准、撞、可读**。

### 与 v2.0 的关系

v2.0 的「卡片零阴影、圆角 6/10、不用胶囊、品牌蓝面积 ≤5%、禁止彩色发光」这五条**已被本版本推翻**。
其余条款——业务真实性、文案红线、状态必须带文字、可访问性——**继续生效，优先级更高**。
两份冲突时，以「不许造假」和「必须读得清」为准。

## 2. Token 分层

| 层 | 文件 | 职责 |
|---|---|---|
| 语义 | `tokens.css` | 纸墨、撞色、圆角、硬投影、三语体、尺寸档位 |
| 映射 | `tailwind.css` | 把语义变量映射成工具类，不新造颜色 |
| 基础 | `base.css` | `@font-face`、纸底网点、焦点双环、印刷工具类 |
| 外壳 | `layout.css` | 竖排书脊、跑马灯顶栏、面包屑条、页面容器 |
| 组件 | `components.css` | 按钮、徽章、卡片、表格、Tabs、空态、弹层 |
| 页面 | `pages/store/skills.css` | 逐页反网格与巨型排版 |

加载顺序即级联优先级，`tailwind.css` 恒在最后。手写样式**不入层**，因此稳定压过工具类。

## 3. 颜色：撞色语义

品牌蓝保留为主操作锚点，与酸柠、洋红硬碰——冲突本身就是识别度。

| Token | 值 | 用途 |
|---|---|---|
| `--paper` / `--paper-2` / `--paper-3` | `#EFE9DC` `#F7F3EA` `#E3DAC7` | 页面底 / 卡面 / 表头与禁用 |
| `--ink` | `#111014` | 文字、边框、硬投影 |
| `--primary` | `#1B6EF3` | 主操作、链接、焦点 |
| `--acid-lime` | `#D8FF3D` | 选中、完成、当前项 |
| `--acid-magenta` | `#FF2E7E` | 需处理、危险、焦点外环 |
| `--acid-orange` | `#FF6A00` | 待补资料、警告 |
| `--acid-cyan` | `#00D1FF` | 进行中、信息 |
| `--stamp` | `#E5004F` | 印章描边、错误 |

**两条硬规则**

1. 撞色只做**底色、描边、投影**，绝不做正文字色。压在撞色底上的字必须是深色（`--ink` 或对应语义的深色版本）。
2. 状态不能只靠颜色。印章、徽章、行首色条都必须带文字。

## 4. 打破的规则（有意的）

| 编号 | 破法 | 边界 |
|---|---|---|
| B01 | 圆角归零 | 唯一例外：不对称切角 `--radius-cut`（`0 0 18px 0`）与筛选胶囊 `--radius-pill` |
| B02 | 硬投影取代柔影 | `6px 6px 0 墨`，模糊恒为 0；颜色随语义换酸柠 / 洋红 |
| B03 | 反网格 | 卡片跨列不等宽 + 阶梯错位 14/20/30/40px + 标题压边 |
| B04 | 倾斜 | 海报卡 ±1.1°、印章 −5°、工单 −0.7°；**只给装饰层，输入与按钮不歪** |
| B05 | 错版 | 标题带 3px 洋红偏移层（`.p-mis`），模拟丝网印套准偏差 |
| B06 | 导航换轴 | 图标栏 → 竖排书脊（`writing-mode: vertical-rl`）；顶栏 → 跑马灯状态条 |
| B07 | 边框升粗 | 常规 2px 墨线，容器 3px；分隔线用 2px 点线（dotted）而非 1px 实线 |

## 5. 守住的底线

| 编号 | 底线 |
|---|---|
| R01 | 正文对比度 ≥ 4.5:1；大字号 ≥ 3:1 |
| R02 | 焦点环可见：3px 墨 + 2px 洋红外环 |
| R03 | 界面文案不得出现开发标记、内部实现说明、内部标识（API 路径、表名、代码变量、`task_id`/`base_url`/`rule`/`en-US` 这类原值） |
| R04 | 不编造销售额、订单量、转化率；后端没给数据就显示空态 |
| R05 | 不放没有功能的假按钮；未开放能力不进导航、不进路由 |
| R06 | 区分「示例数据」「真实计算」「未连接」「未配置」，且必须如实标注 |
| R07 | 尊重 `prefers-reduced-motion`：时长归零、跑马灯静止，版面不受影响 |
| R08 | 名称「激浪」、品牌蓝 `#1B6EF3`、Logo 套件（`docs/brand/logo-v3/`）不动；改 Logo 需先更新套件与 favicon，再同步四处 `?v=` |

## 6. 三语体对撞

| 角色 | 变量 | 栈 | 用在哪 |
|---|---|---|---|
| Display | `--font-display` | Anton（本地 woff2）+ 黑体 | 拉丁海报块、工序编号 |
| 标题 | `--font-sans` + 900 | 系统黑体栈 | 页面标题、卡片标题、印章文字 |
| 正文 | `--font-serif` | 系统宋体栈 | 说明文、段落、对话气泡、空态描述 |
| 标签 | `--font-mono` | JetBrains Mono（本地 woff2）+ Consolas | 表头、徽章、编号、所有数字、状态码 |

- 字体文件放 `frontend/src/assets/fonts/`，用 `/media/fonts/*.woff2` 引用。
  **不要**从 CSS/JS `url()` 相对路径或 `import` 引字体：构建会把它打进 `/assets/*`，而后端没挂载这个前缀 → 404。
- 中文不下载 webfont，用系统黑体 900 与宋体。
- 标题一律负字距（`--tr-tight` = −.035em），等宽标签一律正字距（`--tr-label` = .18em）+ uppercase。
- 数字必须 `font-variant-numeric: tabular-nums`。

工具类（`base.css`）：`.p-title` `.p-display` `.p-serif` `.p-label` `.p-num` `.p-mis` `.p-outline` `.p-stamp` `.p-frame` `.p-cut`。

## 8. 逐页规格

| 路由 | 页面 | 关键手法 |
|---|---|---|
| 登录门 | — | 左：墨底错版海报（巨型黑体 + 洋红描边行 + 三个撞色块）；右：钉在纸上的工单（胶带 + −0.7° + 硬投影） |
| `/dashboard` | 工作台 | 首格巨型指标（墨底酸柠 104px），其余格阶梯错位；趋势无数据时画空框写「不画假折线」 |
| `/workbench` | AI 助手 | 用户消息＝酸柠电报条（右对齐 +0.4°）；助手＝纸面 + 洋红左脊；面板头是墨带；执行步骤用方格编号 + 点线梯 |
| `/tasks` | 任务中心 | 行＝打卡条（左侧状态色脊）；状态＝双层框印章 −5°；底部用真实条数的巨型描边字收尾 |
| `/agents` `/skills` | Agent 市场 / 技能广场 | 海报墙：跨列不等宽 + ±1.1° 倾斜 + 巨型描边汉字水印（`opacity .3`，正文 `z-index 1`，不得糊住按钮） |
| `/data` | 数据资产 | 虚线投递区 + 五步工序（Anton 编号块）+ 字段映射连线 + 校验印章 |
| `/stores/*` | 店铺与渠道 | 收据纸：表头墨底、行用点线、金额等宽右对齐、合计巨型等宽、圆形骑缝章标「示例数据」 |
| `/settings` | 设置 | 工单纸：左墨底分区导航（酸柠高亮），右 kv 点线行；空态用巨型描边字 |

**短页面的死白**一律用排版解决，不用假数据解决：巨型描边数字 + 一句真话（如「07 条真实任务记录」）。

**编号与标签只留给真实关系**：01、02… 只用于工序步骤、执行步骤这类真的有先后的地方，以及来自服务端的真实计数；导航、页签、分区这类并列入口不编号。纯装饰的序号、缩写英文标签（TOTAL / WORK ORDER / SECTION / ROWS 之类）一律不写进界面。

**数字与状态不加复述型副文案**（2026-11-07 定稿）：指标卡下、面板标题旁、卡片标题下都不写复述或自证——「含全部状态」「均来自服务端」「最近执行记录」「草稿与版本」「当前登录身份」这类一律删；时间口径并进标题（如「任务趋势 · 14 天」）。空态只写事实，不写「不画假折线」这类实现说明。
副标只保留两类：真实状态/数据（租户名 · 我的角色、最近 20 条、来源：激浪内置）与操作约束（不提供额度、加密保存、解绑请留空、改密会退出会话）。
真实性标注不受此限——示例数据、规则引擎 / 模型、未连接 / 未配置必须保留。

## 9. 状态视觉

| 状态 | 形式 |
|---|---|
| 已完成 | 酸柠底 + 墨字 + 双层框印章 |
| 进行中 | 电青底 + 脉冲方点 + 文字 |
| 待补资料 / 待确认 | 朱橙底 + 缺失字段清单 + 补充入口 |
| 失败 | 印章红双层框 + 后端真实错误分类 + 可操作建议 |
| 已取消 | 纸 3 底 + 中性文字 |
| 示例数据 | 虚线描边标记 `.mock-flag` + 顶部酸柠提示条 |
| 未配置 | 虚线巨型空态 + 唯一主 CTA |

失败态保留后端错误分类与建议，不许用「出错了，请重试」覆盖有用信息。

## 10. 响应式

- ≥1180px：完整书脊 + 双栏工作台。
- 981–1180px：书脊常驻，页面与顶栏收内边距。
- ≤980px：书脊收到 62px，显示抽屉入口；表格隐藏次要列。
- ≤760px：导航走抽屉；工作台切「对话 / 结果」两段式；表格转卡片；页面不得横向溢出。

竖排书脊在所有断点都保持竖排——它是这套语言的识别点，窄屏只缩字号，不换成横排。

## 11. 工程约束

- 前端：React 19 + TS + Vite，产物必须保持 `dist/index.html + css/ + js/ + assets/`，因为 FastAPI 只挂 `/css` `/js` `/media` 三个前缀。
- 手写样式文件名与顺序固定：`tokens base components layout pages store skills`，加 `tailwind`。新增样式文件要同步改 `vite.config.ts` 的 `HAND_CSS` / `CSS_FILES` 与 `index.html`。
- 禁止从 JS/CSS import 图片与字体（`forbidBundleAssets` 插件会直接报错）。静态资源一律放 `src/assets/` 用 `/media/...` 引用。
- 新动效走 `CPMotion`，时长曲线用 `--dur-1/2/3` + `--ease-out`，跑马灯用 `--dur-4`。
- 动效只做「补齐半截」，不引第三方动画库（2026-11-07 定稿，第一批）：
  - **退场**：条件挂载的抽屉/弹窗用 `hooks/usePresence`，卸载前置 `data-state="closed"`
    播退场（components.css 的 `motion-*-out`），播完才移除节点；Radix 浮层走
    tw-animate-css 的 `data-[state=open/closed]` 进出场类。
  - **墨条**：页签/分区导航的当前项指示用 `lib/tabs.ts` 的 `inkBar`（横 `.tab-ink` /
    竖 `.set-ink`），量位置后滑动；容器必须 `position: relative`；innerHTML 重绘会冲掉
    墨条，inkBar 自己补挂并重新生长。
  - **等待**：busy 用 `.cp-spin`（方头转块）+ 文案 `.btn-swap`（换 key 淡入）；
    shadcn `Button` 有 `busy` prop，`asChild` 时不插 spinner（Slot 只接受单子元素）。
  - **按压**：shadcn `Button` 与手写 `.btn` 同一手感——hover 抬 1px、按下陷 2px、硬投影收掉。
  - **轮询纪律**：轮询刷新只 patch 真的变了的段，禁止整块 innerHTML 重写
    （workbench 结果面板按 head/tabs/body 三段签名比对；`.res-tabs` 节点身份必须稳定，
    否则墨条与滚动位置每秒被冲掉）。启动期与完成时各允许一次整页 render。
  - **降级**：`prefers-reduced-motion` 下 `--dur-*` 归零之外，tw-animate-css 的
    `animate-in/out` 与 `.tab-ink/.set-ink` 过渡、`.cp-spin` 也一并归零（components.css）。

- 页面级动效（第二批，2026-11-07 定稿）：
  - **切页走纸**：`router.ts` 的 `pageFeed` 先把旧页克隆成固定定位的「纸」，再同步换页
    （`flushSync`），旧纸先平移滑出、后段淡掉，新页从右推入。**不用 View Transitions**：
    `document.startViewTransition()` 的更新回调是异步调用的，会让 `go()` 在 DOM 换页前返回，
    破掉「`go()` 返回即新页面」的验收契约。同路径重绘只做淡入；克隆节点超过 2500 个只做进场。
    此时新页加 `.view--fed` 关掉 CSS 兜底进场，遗留页在 `legacy.tsx` 里改播同一条推入。
  - **列表 FLIP**：`hooks/useFlipList`，deps 传列表签名（id 串）。位置用 `offsetLeft/offsetTop`
    量——`getBoundingClientRect` 会把上一轮动画的 transform 算进去，连续筛选会漂移。
    被移除的项由 React 直接卸载，不做退场（要退场得给每项留挂载壳，不值）。
  - **骨架显影**：`Suspense fallback={null}` + `PageVeil`（`usePresence`）。骨架延迟 90ms
    才淡入（快加载不闪），内容挂载后骨架 180ms 淡出，与内容的 `.view` 进场交叠。
  - **叠加顺序**：走纸（0–280ms）覆盖骨架淡入（90–270ms），交接后由骨架承接到内容。
  - **幽灵层隔离**：走纸用的旧页克隆放在 `closed` shadow root 里（样式表启动时就克隆好）。
    `document.querySelector` 穿不过 shadow 边界——否则验收脚本在 `go()` 之后同步查询
    会把旧页元素多数一遍（9 个 chip 变 18），还会撞重复 id。

- 品牌签名动效（第三批，2026-11-07 定稿）：
  - **套准**：`.page-title` 的洋红错版层用 `@property --mis-x` 从 12px 滑回 3px；
    浏览器不支持 `@property` 时保持静态 3px，不改版面。
  - **盖章**：`StatusBadge` 记住上一状态，状态真的变了才换 key 重挂并播 `stamp-slam`；
    首帧不播，避免进页面时一墙徽章同时砸下来。
  - **计数**：`CountUp` 直接改 `textContent`（不走 setState），从上一值滚到新值；
    非数字原样输出，终值永远是后端真值。
  - **图表**：Recharts 的 `isAnimationActive` 按 reduced-motion 开关；手写 SVG 柱体
    首绘时从底部生长、折线用 `stroke-dashoffset` 描出，`WeakSet` 记账保证 resize 重绘不重播。
  - **滚动揭示**：初始隐藏交给 CSS（`html.cp-reveal-on [data-reveal]:not([data-revealed])`），
    不用 JS 设 opacity——设置页的区块是数据回来后才挂载的新节点，JS 在挂载时藏一遍会藏在
    马上被替换的旧节点上。`usePageReveal` 用 MutationObserver 接住晚出现的区块，
    揭示后打 `data-revealed`；另挂滚动扫尾（瞬移到底部不漏）与 1.2s 兜底。
    每页只标 3–6 个区块。

## 12. 验收清单
