# 激浪（Cross-border AI Workspace）设计规范

> 版本：1.1 · 主题：品牌蓝 + 全站液态玻璃 · 适用：当前原生 HTML/CSS/JavaScript 前端

## 1. 设计目标

激浪是跨境电商 AI 运营工作台。视觉需要表达智能、行动、增长和可靠性，不做泛化的“未来科技后台”。

核心原则：
- 品牌蓝保持主色，不做全站换色。
- 玻璃是层级材料，不是每个组件的默认皮肤。
- 数据密集区优先可读性；模糊、透明和渐变只用于导航、浮层、重点区域。
- 演示数据必须诚实标注，不将模拟结果呈现成真实店铺经营数据。
- 真实交互优先，装饰不能覆盖或替代产品功能。

## 2. 色彩 Token

| Token | 值 | 用途 |
|---|---|---|
| `--brand` | `#1B6EF3` | 主要操作、链接、选中图标 |
| `--brand-dark` | `#1557C0` | Hover、深色强调 |
| `--brand-soft` | `#EAF2FF` | 选中导航、轻提示背景 |
| `--bg` | `#F4F6FA` | 页面底色 |
| `--surface` | `#FFFFFF` | 表格、输入框、基础面板 |
| `--ink` | `#101828` | 标题和主要正文 |
| `--ink-soft` | `#344054` | 次级正文 |
| `--muted` | `#667085` | 辅助文字 |
| `--glass-bg` | `rgba(255,255,255,.78)` | 轻玻璃表面 |
| `--glass-line` | `rgba(255,255,255,.88)` | 玻璃高光边界 |
| `--glass-blue-line` | `rgba(27,110,243,.18)` | 品牌蓝玻璃描边 |

语义色继续沿用现有 `--ok`、`--warn`、`--danger`、`--info`，不得用品牌蓝替代成功/警告/错误语义。

## 3. 液态玻璃使用规则

### 适合使用
- 顶部导航：轻微透明、`backdrop-filter` 模糊，保持文字清晰。
- 侧边栏：接近不透明的白色，避免滚动内容透过导航干扰阅读。
- 悬浮面板、菜单、AI 助手入口：可使用半透明白、细亮边和柔和阴影。
- 品牌视觉：可在独立 Logo/插画中使用冰蓝玻璃和流动高光。

### 不适合使用
- 数据表格主体、长文本、表单输入区：保持高对比、不透明底色。
- 所有卡片同时叠加 blur、强渐变、重阴影。
- 低对比度的白字透明玻璃按钮。
- 用动画或高光干扰高频操作。

推荐表面：白色或 90% 以上不透明；模糊主要用于其后方内容确实需要柔化的浮层。必须提供不支持 `backdrop-filter` 时的纯色回退。

## 4. 图标与品牌

- 使用项目现有内联 SVG 图标体系，不额外加载图标 CDN。
- 常规图标使用统一 24×24 viewBox，导航视觉尺寸约 17–18px，按钮图标约 16px。
- 使用圆角端点、统一描边和明确的负空间。
- 图标颜色默认继承文字；选中项使用品牌蓝，语义状态使用语义色。
- 不给每个图标单独套彩色底块。只为品牌 Logo、空状态和少量重要入口提供图形容器。
- Logo 在侧边栏 28px 尺寸下仍应保持辨识度。

## 5. 布局、间距与形状

- 侧边栏宽度和现有折叠逻辑保持不变。
- 页面标题与描述建立清楚的层级，页面操作放在标题区右侧。
- 卡片圆角目标 14–16px；表单控件约 10px；徽标使用胶囊形。
- 使用现有间距 Token（4/8/12/16/24/32px），避免页面随意设置不同间距。
- 卡片阴影应柔和、低扩散；Hover 以边框和轻微阴影变化为主，不做明显浮起动画。
- 表格保持清楚的行分隔和表头背景，避免玻璃透明叠加导致内容难读。

## 6. 数据资产页面规则

- 页面标题：数据资产。
- 说明文案以用户任务为中心，避免“Mock、Seed、Connector”等工程术语。
- 顶部全局提示使用“演示环境”表达数据来源，不解释内部模拟实现。
- 隐藏普通用户不需要的数据源内部 ID；在诊断或详情场景按需提供。
- 字段映射下拉选项优先显示中文业务名称，底层字段 key 保持不变。
- 对演示数据使用一致的“演示数据”标识；导入数据使用“已导入”等准确状态。
- 不得把模拟数据标记成已连接店铺数据。
- 导入、校验、提交、错误 CSV 导出等现有功能和接口行为必须保留。

## 7. 交互与可访问性

- 所有按钮保留 hover、active、disabled、focus-visible 状态。
- 不用颜色作为唯一状态提示；状态同时提供文字。
- 保持键盘导航和可见焦点。
- 尊重 `prefers-reduced-motion` 和 `prefers-reduced-transparency`。
- 错误提示说明用户可以采取的下一步，内部堆栈留在日志。
- 移动端避免侧栏、表格和卡片产生不必要的横向溢出。

## 8. 验收清单

- [ ] 品牌蓝仍为主要交互色。
- [ ] 顶部导航玻璃效果克制且文字清晰。
- [ ] 侧边栏选中态清楚，图标尺寸和描边一致。
- [ ] 数据表格保持高可读性。
- [ ] 页面不再向普通用户展示 Mock/Seed 等开发者术语。
- [ ] 模拟数据和用户导入数据能被清楚区分。
- [ ] 数据源内部 ID 不再占用主要概览位置。
- [ ] 原有路由、上传、校验、字段映射和提交功能没有被视觉改造破坏。

## 数据资产页面视觉落地补充

- 数据资产页采用「液态玻璃品牌 Hero + 数据概览 + 文件导入/校验 + 数据集列表」层级。
- 品牌蓝 `#1B6EF3` 保持为唯一主交互色，冰蓝与透明白仅作为表面、描边和高光。
- Hero 的抽象浪潮使用 `assets/liquid-wave.svg`，作为装饰层，不承载业务信息。
- 数据集统计、最近导入和状态均来自 `/api/data-sources` 或当前导入结果；无记录时显示空状态，不填充伪造数据。
- 文件导入仍走现有 `/api/import/preview`、`/api/import/remap` 和 `/api/import/commit` 接口，视觉改造不改变接口协议。
- 玻璃效果集中用于 Hero、概览卡片和轻量表面；表格维持高可读性，避免对数据密集区施加强模糊。


## 9. 全站背景层与品牌液态玻璃（v1.1）

- 新增 `css/liquid-glass.css`，加载顺序在 `pages.css` 之后，用于跨页面的共同视觉层，不改变页面业务逻辑。
- 全站底层使用冷白到冰蓝的柔和渐变、品牌蓝环境光，以及 `/media/liquid-wave.svg` 的液态波浪；背景应从卡片间隙和透明区域可见。
- 数据资产页 Hero、常规业务页标题区、登录页、AI 助手空状态与结果区均复用同一波浪语言；数据表格保持足够不透明以保障可读性。
- 资源统一通过 `/media/liquid-wave.svg?v=3` 引用，避免原相对路径 `/assets/` 在当前服务静态资源映射下加载失败。
- 对 `prefers-reduced-transparency: reduce` 提供纯色回退；小屏幕下缩小背景层以减少不必要的绘制成本。
- 品牌主色仍为 `#1B6EF3`，禁止用装饰渐变替换语义状态色。
